# RTL for Claude Desktop

תמיכה בכתיבה מימין לשמאל ב-**Claude Code שבאפליקציית Claude לדסקטופ**. תשובות בעברית, בערבית ובפרסית מוצגות מימין לשמאל, ואנגלית, קוד ונוסחאות נשארים משמאל לימין.

[English](README.md) · [עברית](README.he.md)

## מה הוא עושה

- **זיהוי כיוון חכם:** בלוק נחשב RTL אם התו החזק הראשון שלו הוא RTL, אחרי דילוג על שם קובץ, כתובת URL, נתיב או קוד בתחילתו. אם הבדיקה הזו יוצאת LTR, הבלוק עדיין נחשב RTL כשיש בו יותר אותיות RTL מאותיות לטיניות.
- **פסקאות** שמתחילות ב-`index.js`, בפקודה או במונח באנגלית מוצגות נכון.
- **פסקאות מעורבות:** שורה באנגלית בתוך פסקה בעברית, או להפך, שומרת על סדר הקריאה שלה.
- **רשימות:** הכיוון נקבע לפי כל הפריטים, לא רק לפי הראשון.
- **טבלאות:** הכיוון נקבע בהצבעת רוב על שורת הכותרות והעמודה הראשונה, וכל תא מוצג בכיוון שלו.
- **קוד, חשבון ו-LaTeX** בתוך שורה (`2 + 3 = 5`, `$x^2$`) נשארים משמאל לימין ולא מתהפכים.
- **בלוקי קוד** לא משתנים בכלל.
- **ההודעות שלך** מתוקנות גם הן.
- **`/rtl`** מדליק ומכבה את התיקונים, וההגדרה נשמרת בין sessions.

## התקנה

בתוך Claude Code:

<div dir="ltr">

```
/plugin marketplace add xShakedDev/RTL-For-Claude-Desktop
/plugin install smart-rtl@smart-rtl
```

</div>

או מהטרמינל:

<div dir="ltr">

```sh
claude plugin marketplace add xShakedDev/RTL-For-Claude-Desktop
claude plugin install smart-rtl@smart-rtl
```

</div>

הפלאגין משתמש בממשק ה-function hooks של Claude Code, שעדיין נמצא ב-early access. הוא נבדק עם Claude Code 2.1.289.

## תיקון פריסת החלון ב-Windows

כש-Windows מוגדר לשפת תצוגה עברית או ערבית, Claude Desktop פורס את החלון מימין לשמאל: פקדי החלון מסתירים את הכפתורים של האפליקציה, וחלונית הדפדפן נפתחת במקום הלא נכון. פלאגין לא יכול לתקן את זה, ולכן יש בריפו סקריפט הפעלה קטן, [`windows/claude-ltr.ps1`](windows/claude-ltr.ps1). הוא מפעיל את Claude עם הדגל `--force-ui-direction=ltr` של Chromium, ולא משנה אף קובץ של האפליקציה.

כדי להוסיף קיצורי דרך בשם **Claude (LTR)** לשולחן העבודה ולתפריט התחל, מריצים ב-PowerShell:

<div dir="ltr">

```powershell
irm https://raw.githubusercontent.com/xShakedDev/RTL-For-Claude-Desktop/main/windows/claude-ltr.ps1 -OutFile $env:TEMP\claude-ltr.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\claude-ltr.ps1 -Install
```

</div>

מעכשיו פותחים את Claude מהקיצור הזה. אם Claude כבר פתוח בלי התיקון, הקיצור מפעיל אותו מחדש. הקיצור ממשיך לעבוד גם אחרי עדכונים של Claude. כדי להסיר את הקיצורים, מריצים את הסקריפט עם `-Uninstall`.

## איך זה עובד

לפלאגין אין גישה ל-CSS ואין לו אפשרות לקבוע `dir`. במקום זה הוא משכתב את הטקסט של כל הודעה רגע לפני שהיא מוצגת, ומוסיף לה תווי בקרה בלתי נראים של Unicode. ההודעה שנשמרת בשיחה לא משתנה.

- **`RLM`** בתחילת בלוק גורם לזיהוי הכיוון המובנה של האפליקציה להתייחס לבלוק כ-RTL.
- **`RLI` / `LRI` … `PDI`** מבודדים שורה, פריט ברשימה, תא בטבלה, קוד או נוסחה, כך שכל אחד מהם שומר על הכיוון שלו.

## מגבלות

- **יישור:** במקומות שאין בהם זיהוי כיוון מובנה, כמו ההודעות שלך, סדר הקריאה מתוקן אבל הטקסט נשאר מיושר לשמאל.
- **תיבת הקלט:** לא משתנה.
- **גופנים:** פלאגין לא יכול לשנות גופנים. לפריסת החלון, ראו [תיקון פריסת החלון ב-Windows](#תיקון-פריסת-החלון-ב-windows).
- **טרמינל:** לא משתנה, כי בחלק מהטרמינלים תווי הבקרה מוצגים כסימנים.
- **העתקה:** העתקה של הודעה עלולה לכלול את תווי הבקרה הבלתי נראים.
